# 0.1.1 Critical Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the dead gradient telemetry (#1/#2) and the broken `run_scratch.py --quick` path (#5), record the validation decisions, and publish `cnn-classifier-toolkit` 0.1.1 to PyPI and GitHub.

**Architecture:** Add a batch-level callback hook so `GradientMonitor` and `NaNDetector` see gradients while they still exist. The trainer unscales AMP gradients once, runs the hook before clipping/step, stops before `optimizer.step()` if nonfinite gradients are seen, and merges callback-added metrics back into the current history row so `grad_norm` reaches every artifact. Separately, add the missing null sample-limit keys to the CIFAR config so the existing quick overrides apply. Version, changelog, and backlog updates then go through the existing tag-driven release workflow.

## Review Focus

- **AMP:** unscale exactly once per optimizer window before monitoring and clipping; never double-unscale.
- **Artifact consistency:** `grad_norm` must reach `history.csv`, `metrics.jsonl`, `summary.json`, and the report figure input.
- **Backward compatibility:** a custom callback without `on_batch_end` must not crash the trainer.

- **Quick mode:** the full CIFAR config keeps unlimited samples; only the quick overrides set the limits.

- Add `on_batch_end` to `Callback` and `_NoOpCallback`.
- Replace `GradientMonitor` with a batch collector:

```python
class GradientMonitor(_NoOpCallback):
    def __init__(self) -> None:
        self.last_report: dict[str, float] = {}

    def on_train_start(self, state: TrainingState) -> None:
        self.last_report = {}

    def on_batch_end(self, state: TrainingState) -> None:
        report: dict[str, float] = {}
        for name, parameter in state.model.named_parameters():
            if parameter.grad is not None:
                report[name] = float(parameter.grad.detach().norm().item())
        self.last_report = report

    def on_epoch_end(self, state: TrainingState) -> None:
        if self.last_report:
            state.metrics["grad_norm"] = float(
                sum(value * value for value in self.last_report.values()) ** 0.5
            )
```

- Add the gradient guard to `NaNDetector` and keep the epoch metric check:

```python
    def on_batch_end(self, state: TrainingState) -> None:
        for parameter in state.model.parameters():
            if parameter.grad is not None and not bool(torch.isfinite(parameter.grad).all()):
                self.failed = True
                state.stop_requested = True
                return

    def on_epoch_end(self, state: TrainingState) -> None:
        values = list(state.metrics.values())
        if any(not math.isfinite(float(value)) for value in values):
            self.failed = True
            state.stop_requested = True
```

- [ ] **Step 6: Implement the trainer ordering**

In `src/cnn_classifier/training/trainer.py`, add:

```python
    def _run_batch_hooks(self) -> None:
        for callback in self.callbacks:
            hook = getattr(callback, "on_batch_end", None)
            if callable(hook):
                hook(self.state)
            if self.state.stop_requested:
                break
```

Replace the optimizer-window block in `_train_epoch` with:

```python
            if should_step:
                if self.scaler is not None:
                    self.scaler.unscale_(self.optimizer)
                self._run_batch_hooks()
                if self.state.stop_requested:
                    self.optimizer.zero_grad(set_to_none=True)
                    break
                if self.config.training.grad_clip_norm is not None:
                    torch.nn.utils.clip_grad_norm_(
                        self.model.parameters(), self.config.training.grad_clip_norm
                    )
                if self.scaler is not None:
                    self.scaler.step(self.optimizer)
                    self.scaler.update()
                else:
                    self.optimizer.step()
                self.optimizer.zero_grad(set_to_none=True)
                if self.config.training.scheduler.step_unit == "batch":
                    if isinstance(self.scheduler, torch.optim.lr_scheduler.ReduceLROnPlateau):
                        raise ConfigError("plateau scheduler requires epoch stepping")
                    self.scheduler.step()
```

After the epoch callback loop in `fit()`, add:

```python
            self.state.history[-1].update(self.state.metrics)
```

The order is deliberate: unscale once, let callbacks inspect real gradients, stop before the step if requested, then clip and step.
