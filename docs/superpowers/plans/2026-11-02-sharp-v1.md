# CNN Classifier Sharp v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a config-driven, tested, publishable PyTorch CNN classification toolkit, then add the CIFAR-10, optical-degradation, ablation, and bring-your-own-data demos.

**Architecture:** A `src/`-layout Python package with typed YAML configuration (`cnn_classifier.config`), registered dataset adapters (`cnn_classifier.data`), registered model builders (`cnn_classifier.models`), a headless pure-PyTorch trainer (`cnn_classifier.training`), evaluation and fairness comparison (`cnn_classifier.evaluation`), diagnostics (`cnn_classifier.diagnostics`), artifact-driven visualization/reporting (`cnn_classifier.viz`), and a Typer CLI (`cnncls`). The core library is built and reviewed before any demo is added.

**Tech Stack:** Python 3.11–3.13, `uv`, `hatchling`, PyTorch 2.15.0, TorchVision 0.29.2, Pydantic v2, PyYAML, NumPy, Pillow, tifffile, Matplotlib, Jinja2, Typer, Rich, pytest, ruff, mypy, pre-commit, MkDocs Material, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-02-cnn-classifier-design.md`

## Global Constraints

- Python 3.11–3.13; `uv`; committed `uv.lock`; project-local `.venv/` gitignored.
- `src/` layout; distribution `cnn-classifier-toolkit` (originally planned as `cnn-classifier`); import `cnn_classifier`; CLI `cnncls`; Apache-2.0.
- PyTorch 2.15.0 and TorchVision 0.29.2 are the verified current versions on 2026-11-02. Pin them in `uv.lock`; use compatible lower bounds in `pyproject.toml`.
- Pydantic v2 configs with `extra="forbid"` for known models, `schema_version: "1.0"`, and CLI overrides.
- Device resolution: CUDA → MPS → CPU for `auto`. MPS is the acceptance device; no CUDA is assumed.
- Training never imports `matplotlib`, `jinja2`, or `viz`. Reporting reads run artifacts.
- The test split is never used for model selection. `Trainer.fit()` must not iterate the test loader.
- Diagnostic models: `simple_cnn`, `residual_cnn`, `torchvision.*`. No MLP, VGG, Lightning, Hydra, ONNX, sweep runner, profiler, VisualTorch, or TorchView in v1.
- Sharp v1 transfer configs: three 32×32 runs (scratch, linear probe, fine-tune). 224×224 tracks and budget sensitivity are v1.1.
- Sharp v1 ablations: augmentation, BatchNorm, residual connections, LR schedule.
- Demos: CIFAR-10, optical degradation, four ablations, bring-your-own-data. No `notebooks/` or `examples/` directories.
- Results: `results/<demo>/`; run artifacts: `runs/` (gitignored); checkpoints not committed.
- Coverage ≥90% for core modules; visualization is covered by smoke tests. `ruff check`, `ruff format --check`, and `mypy src` must pass.
- Commit messages end with `Co-Authored-By: Claude Code <noreply@anthropic.com>`.
- Canonical URLs: `https://github.com/pengzhao-ai/cnn-classifier`; docs `https://pengzhao-ai.github.io/cnn-classifier/`.
- Full MPS suite estimate: 2.5–4 hours, run in resumable stages after core review.

## Review Focus

1. **Group leakage and test fingerprints** — a split or comparison that mixes source groups, or compares runs with different test fingerprints, must fail loudly. Tests: Task 4 (`test_group_split_has_no_overlap`), Task 7 (`test_inspection_detects_group_leakage`), Task 16 (`test_compare_refuses_mismatched_fingerprints`).
2. **16-bit image contract** — 16-bit TIFF/PNG must not be silently truncated to 8-bit or given an undocumented range. Tests: Task 5 (`test_16bit_tiff_preserves_range`, `test_fixed_range_scales_16bit`), Task 25 (`test_byo_quickstart_trains_and_writes_contract`).
3. **Checkpoint/resume integrity** — a resume with a different config, class map, or normalization must be rejected. Tests: Task 12 (`test_checkpoint_roundtrip_and_mismatch`), Task 14 (`test_resume_continues_from_last_checkpoint`).
4. **Transfer setup validity** — a frozen `adapt_3x3` stem is invalid; freeze modes and regex param groups must not silently match nothing. Tests: Task 9 (`test_frozen_adapt_3x3_is_rejected`, `test_unmatched_param_group_raises`).
5. **Test-set contamination** — training must never touch the test loader. Tests: Task 14 (`test_fit_writes_history_and_never_touches_test_loader`, `test_training_import_does_not_import_plotting_stack`).
